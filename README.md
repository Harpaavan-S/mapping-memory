# Mapping Memory
In this project, I developed a program which uses Unity 2D and the Muse EEG headset to create a cheaper and more accessible way to measure one's memory which, in turn, can help identify and treat memory problems early before they worsen and become irreversable.
## Materials
For this project I used the Muse EEG headset. All programs were run on my Macbook Air. Regarding software, I used BrainFlow to connect the headset to my laptop. All the programs were coded in Python. All the games were designed in Unity 2D and coded with C#. The programs actually create a PDF file that will review the results and present them in an understandable way for the participant. Assets include the PressStart2P font asset for text components.
## Run it locally
To run this on your laptop, you will need to have the Muse EEG headset. Also you may have to modify some of the existing code to be specific to your Muse headset and laptop. Clone the repository and open up the Unity project. While you are playing the games, wear the headset and run the programs. Everything will be saved onto your laptop. I suggest tinkering around with it on your laptop until it works, and maybe you'll discover something new!
